# 企业 OA 协同办公系统 V1.0 - 项目文档

## 目录结构

```
docs/
├── 01-需求分析/           ← 业务需求、功能定义
│   ├── 需求文档.md        ← 原始需求文档
│   ├── 需求分析.md        ← 需求分析总结
│   └── 功能模块.md        ← 功能模块划分
│
├── 02-产品设计/           ← 产品层面的设计文档
│   ├── 页面需求.md        ← 各页面的功能需求
│   └── API输入文档.md     ← API设计的输入依据
│
├── 03-技术方案/           ← 技术实现方案
│   ├── 技术选型.md        ← 技术栈选择
│   ├── 系统架构.md        ← 系统整体架构
│   ├── 数据库设计.md      ← 数据库表结构设计
│   └── API设计.md         ← RESTful API 设计
│
├── 04-开发规范/           ← 开发规范与模块划分
│   ├── 前端模块划分.md    ← 前端目录结构与模块规划
│   └── 后端模块划分.md    ← 后端目录结构与模块规划
│
└── 05-UI设计/             ← 界面设计
    └── wireframes/        ← 低保真布局草图 (29张)
```

## 文档阅读顺序

建议按以下顺序阅读：

1. **01-需求分析** - 了解项目要做什么
2. **02-产品设计** - 了解页面需求和API输入
3. **03-技术方案** - 了解技术实现方案
4. **04-开发规范** - 了解代码组织方式
5. **05-UI设计** - 参考界面布局
