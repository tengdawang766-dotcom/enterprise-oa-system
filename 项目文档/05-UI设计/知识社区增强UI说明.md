# 知识社区增强 UI 说明

状态：已完成。全部增强页面已实现并通过 516 项测试与浏览器验收。

## 文章详情增强

正文下方依次展示点赞/收藏操作区和评论区。点赞按钮显示总数及本人状态；收藏只显示本人状态。评论区包含计数、纯文本输入、提交状态、分页列表；已删除评论显示占位文案，不显示原内容。文章非公开时普通读者无法进入详情或评论区。

## 我的收藏 `/app/knowledge/favorites`

卡片列表展示可用文章的标题、摘要、分类、作者和收藏时间。失效收藏只显示“文章已不可用”、收藏时间和移除按钮，不渲染标题、摘要或正文。

## 管理员知识内容管理 `/app/admin/knowledge`

文章 Tab 支持状态/分类/标题筛选和分页，详情抽屉展示公开或待审核内容、处理日志，下架和驳回必须填写原因。评论 Tab 支持文章标题/评论人筛选和管理员删除。

## AI 辅助写作

编辑页增加“AI 辅助”抽屉，包含生成草稿、润色选中文本、整理结构和生成摘要。结果在独立预览区显示，只有员工点击“插入/替换选中内容”才修改本地表单；取消不改变原文，失败保留输入。

## AI 知识查询 `/app/knowledge/ask`

问题输入区下方展示回答和“依据来源”卡片。来源由后端返回并链接到真实文章。无依据时展示明确空结果，不提供虚构链接。

## 通用状态

全部页面覆盖 loading、empty、error、retry、disabled 和重复提交状态；纯文本通过 React 文本节点和 pre-wrap 渲染。
