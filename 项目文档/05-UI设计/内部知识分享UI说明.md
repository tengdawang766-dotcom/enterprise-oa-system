# 内部知识分享 UI 设计说明

状态：已完成（Day 8）。本文件是第一版低保真布局规范，现有 29 张 OA 线框图保持历史准确性，未直接修改。实际实现 4 个页面：文章列表、文章详情、文章编辑、我的文章。

## 统一布局

沿用员工端左侧导航、顶部用户区和内容卡片。侧边栏在“公告”后增加“知识分享”。使用 Ant Design Card、Table/List、Form、Input、Select、Tag、Pagination、Result 和 Modal。

## 页面布局

### 文章列表

顶部标题和“新建文章/我的文章”按钮；下一行放标题搜索、分类筛选和查询/重置；正文区域以卡片列表展示标题、摘要、分类、作者、发布时间，底部分页。

### 文章详情

顶部返回按钮；标题下展示分类、作者、发布时间和状态；正文使用保留换行的纯文本区域。作者按状态看到编辑、发布或撤回按钮。

### 文章编辑

单列表单：标题、分类、摘要、正文；底部“保存草稿/保存修改”和取消。字段错误就近展示，提交期间禁用重复操作。

### 我的文章

顶部新建按钮；筛选区包含标题、分类、状态；表格显示标题、分类、状态、创建时间、更新时间和状态相关操作。

## 状态与异常

DRAFT 使用默认色，PUBLISHED 使用绿色，WITHDRAWN 使用灰色。列表无数据展示 Empty，请求失败展示 Result 与重试按钮，403/404 使用现有错误页风格。

## 增强页面关联（已完成）

现有四个知识分享页面保持已完成。评论、点赞收藏、管理和 AI 增强不改写原设计，新增交互统一记录在 `知识社区增强UI说明.md`。全部增强页面已实现并通过浏览器验收。
