# 企业 OA 系统 V1.0 页面需求

## 1. 登录页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 系统名称、登录表单、忘记密码请联系管理员的提示               |
| 操作入口     | 账号输入框、密码输入框、登录按钮                             |
| 权限与状态   | 所有用户可访问；停用账号不能登录                             |
| 操作结果     | 登录成功进入工作概览；首次登录或密码重置后进入修改密码页     |
| 异常反馈     | 必填项为空提示补充；登录失败提示账号或密码错误、账号停用或请求失败 |

## 2. 修改密码页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 密码规则、是否必须修改密码的提示                             |
| 操作入口     | 当前密码、新密码、确认新密码、提交按钮；日常修改可取消，强制修改可退出登录 |
| 权限与状态   | 已登录用户可操作；首次登录或重置密码后必须改密，不能跳过进入其他业务 |
| 操作结果     | 修改成功，原登录状态失效，提示重新登录                       |
| 异常反馈     | 当前密码错误、新密码不足 8 位或未包含字母和数字、两次输入不一致、请求失败时明确提示 |

## 3. 工作概览页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 员工：未读公告数量、本人待审批数量、最近申请结果；负责人额外看到待本人审批数量；管理员：启用员工及负责人总数、部门数量、公告草稿数量 |
| 操作入口     | 统计卡片、最近申请记录、对应业务入口                         |
| 权限与状态   | 按当前角色展示，只能查看有权访问的信息                       |
| 操作结果     | 点击进入对应列表或详情；列表携带相应筛选条件；刷新更新统计   |
| 异常反馈     | 无记录显示“暂无记录”，数量为零正常显示；加载失败提示重试，不能将失败显示为零 |

## 4. 个人资料页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 登录账号、姓名、角色、部门、职务、工作邮箱、联系电话；管理员部门显示“不适用” |
| 操作入口     | 邮箱和联系电话编辑框、保存按钮、修改密码入口                 |
| 权限与状态   | 所有角色只能维护本人资料；姓名、账号、角色、部门、职务只读   |
| 操作结果     | 保存成功提示并显示最新资料，通讯录反映更新后的联系方式       |
| 异常反馈     | 邮箱或电话格式不合法时指出字段；保存失败保留输入并提示重试   |

## 5. 员工管理页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 账号、姓名、部门、角色、职务、联系方式、启用状态，不展示密码 |
| 操作入口     | 姓名或账号搜索、部门／角色／状态筛选、创建账号、编辑资料、调整部门及角色、重置密码、启用／停用 |
| 权限与状态   | 仅管理员操作；账号不可修改或删除；存在相关待审批申请或未处理任务时，限制人员调整及停用；不能停用自己 |
| 操作结果     | 成功后更新列表；重置密码提示原登录失效、下次登录须改密；停用后禁止账号继续访问 |
| 异常反馈     | 账号重复、必填项缺失、部门或负责人设置冲突、存在待办限制时说明原因；请求失败保留输入 |

## 6. 部门管理页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 部门名称、负责人；无负责人时显示“未设置”                     |
| 操作入口     | 新增部门、修改名称、分配／更换负责人、删除部门               |
| 权限与状态   | 仅管理员操作；负责人须为本部门启用账号；有相关待办时限制调整；有关联账号或历史申请时禁止删除部门 |
| 操作结果     | 成功后更新部门列表；更换后原负责人恢复为员工；无负责人时提示该部门员工暂不能提交请假 |
| 异常反馈     | 名称为空或重复、负责人不符合条件、调整或删除受限时说明具体原因；失败不改变原信息 |

| 操作结果     | 按条件更新人员列表                                           |
| 异常反馈     | 无匹配结果提示调整条件；加载失败提供重试入口                 |

## 8. 公告列表页

| 要确定的内容 | 说明                                                         |

| 异常反馈     | 无公告或无搜索结果显示相应提示；打开时已撤回则提示不可查看；加载失败可重试 |

## 9. 公告详情页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 标题、正文、发布人、发布时间；管理员额外看到状态、阅读人员及首次阅读时间；草稿显示“未发布” |

| 异常反馈     | 公告不存在、已撤回或无权访问时，不展示受限正文；无阅读记录显示“暂无阅读记录”；请求失败可重试 |

## 11. 我的请假页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 本人申请的类型、开始日期、结束日期、天数、状态、审批人、提交时间，按提交时间倒序 |
| 操作入口     | 状态／类型／开始日期范围筛选、分页、详情入口、发起申请弹窗   |
| 权限与状态   | 员工和负责人只能查询本人申请；员工由本部门负责人审批，负责人选择另一部门启用负责人；无合格审批人时不能提交 |
| 操作结果     | 根据日期计算天数；提交成功关闭弹窗，列表新增待审批记录；不提供修改或删除原申请的入口 |
| 异常反馈     | 日期不合法、超过 30 天、原因缺失或超长、日期重叠、缺少审批人时说明原因；失败保留输入；无申请显示空状态 |

## 12. 请假详情页

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 申请人、提交时部门、类型、日期、天数、原因、指定审批人、当前状态、提交时间、最终操作人及时间、审批意见或撤销记录 |
| 操作入口     | 返回；待审批时申请人可撤销，指定审批人可通过／驳回；审批意见输入框 |
| 权限与状态   | 仅申请人和指定审批人可查看；原负责人可查看自己曾处理的记录；管理员无权查看；最终状态仅可查看 |
| 操作结果     | 撤销和审批前确认；成功后更新状态与记录，移除不再可用的操作；撤销后需要更正内容，应另行发起新申请 |
| 异常反馈     | 驳回未填写原因、意见超过 500 字时提示；已被另一方处理则提示并刷新；不存在或无权访问时不展示内容 |

## 13. 审批工作台

| 要确定的内容 | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 展示信息     | 待我审批和历史记录；申请人、提交时部门、类型、日期、天数、状态、提交时间、最终处理时间 |
| 操作入口     | 待办／历史切换、申请人姓名搜索、历史状态筛选、分页、详情入口 |
| 权限与状态   | 负责人只查看分配给自己的申请；卸任者仅保留曾处理记录的查询入口，不获得新的审批权限 |
| 操作结果     | 进入详情处理；处理或撤销后从待办移入历史，更新数量；待办按提交时间正序，历史按最终处理时间倒序 |
| 异常反馈     | 无待办显示“暂无待审批申请”；无历史显示空状态；记录状态发生变化时更新；加载失败可重试 |

## 通用交互要求

- 列表区分加载中、无数据、加载失败，并支持分页。
- 提交过程中防止重复点击，失败时保留用户输入。
- 网络结果不确定时，提示查询最新状态，不直接显示成功。
- 登录失效提示重新登录，无权限不展示受限信息。
- 重要操作成功后，相关详情、列表和概览在后续访问或刷新时反映最新结果。
- 界面以中文、电脑浏览器使用为主。

## 内部知识分享页面需求（已完成）

状态：已完成（Day 8）。

### 文章列表 `/app/knowledge`

- 展示：标题、摘要、分类、作者、发布时间；只展示已发布文章。
- 操作：标题搜索、分类筛选、分页、查看详情、进入新建和我的文章。
- 异常：无数据展示空状态；请求失败展示错误和重试入口。

### 文章详情 `/app/knowledge/articles/:id`

- 展示：标题、分类、作者、发布时间、更新时间、正文。
- 权限：已发布文章对有效员工可见；草稿和已撤回文章仅作者可见。
- 作者操作：草稿可编辑/发布，已发布可编辑/撤回，已撤回仅查看。

### 文章编辑 `/app/knowledge/editor`、`/app/knowledge/editor/:id`

- 字段：标题、分类、摘要、正文。
- 新建：保存后生成草稿。
- 编辑：只允许作者编辑草稿或已发布文章；保存成功进入详情或我的文章。
- 校验：按需求文档字段规则显示表单反馈。

### 我的文章 `/app/knowledge/mine`

- 展示：本人全部文章的标题、分类、状态、创建和更新时间。
- 操作：标题搜索、分类/状态筛选、分页、查看、编辑、发布、撤回。
- 状态按钮：DRAFT=查看/编辑/发布，PUBLISHED=查看/编辑/撤回，WITHDRAWN=查看。
