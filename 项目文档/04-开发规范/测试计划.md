# 企业 OA 测试计划

## 内部知识分享增量（已完成）

### 后端

- API 正常流程：分类、创建、修改、发布、撤回、列表、详情、我的文章。
- 状态与归属：重复发布/撤回、撤回终态、非作者修改/发布/撤回。
- 可见性：他人草稿和撤回文章返回 404，已发布文章可见。
- 查询：标题搜索、分类筛选、状态筛选、分页 total 与 items 一致。
- 认证：未登录 401、强制改密 403、管理员 403、停用员工 401。
- 隔离：使用 RUN_ID 创建数据并精确清理，不执行无条件 deleteMany。

### 前端

- API 路径、参数和请求体。
- 菜单与路由可达性。
- 状态到操作按钮的映射。
- 表单校验、空状态和错误反馈。

### 回归与交付门禁

后端和前端全量测试、两端构建、Prisma Migration 状态、`git diff --check`。浏览器验证完整文章流程和关键权限场景。测试结果只能在实际执行后写入测试报告。
